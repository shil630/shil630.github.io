🔥 Pre-mortem 事前验尸（致命隐患排雷）

反过来想，总是反过来想：假设 1 年后这笔投资暴跌 50%，最致命、最可能的原因是什么？提前把最坏的死因摆在桌面上。

C估值透支与安全边际核对

估值不是精确目标价。记录价格透支了多少乐观预期，以及怎样的经营逆风会击穿底线。

02 / SIZE

组合角色与硬纪律边界

看好不等于重仓。用硬顶上限（Hard Cap）和最大容忍亏损约束贪婪，严禁越跌越买。

A务实的两段式建仓与加仓纪律

严禁纯因“股价下跌”而盲目加仓补仓。加仓必须满足：有新证据进一步强化逻辑，且加仓后绝不突破 Hard Cap。

阶段价格 / 事件触发条件必须验证的基本面事实与动作阶段后仓位 (≤ Hard Cap)
03 / EXIT

什么新证据会让我行动？（出场与冷静）

把逻辑退出、削峰再平衡和情绪预警分开。价格触发复核，基本面决定动作。

A复核与逻辑退出（止损底线）

B止盈 / 削峰再平衡纪律

止盈不等于猜顶部。当估值严重透支，或暴涨导致持仓市值被动突破 Hard Cap 时，按规则削峰。
